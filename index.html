Core Principles

How I build mobile software.

Architecture & Modularity

Clean Architecture

Strict separation between Presentation, Domain (Entities, Use Cases), and Data (Repositories, Data Sources). Feature-first modular organization that scales gracefully across multiple squads without circular dependencies.

Reliability & Testing

Predictable State

Adopting BLoC/Cubit for explicit, immutable states and unidirectional data flow. Code designed for testability, thorough unit tests for use cases and state transitions, and robust crash analytics tracking.

Production Execution

End-to-End Delivery

Experienced in taking ideas from product specs to Google Play & App Store release. Integrating native SDKs, handling offline synchronization (Hive/SQLite), and automating deployment via CI/CD pipelines.
